# ddnet-automap-creator

Visual editor to easily create DDNet [automappers](https://wiki.ddnet.org/wiki/Automapper). Based on [SimpleDDNetAutomapper](https://github.com/AssassinTee/SimpleDDNetAutomapper) by Assa, uses [r++](https://github.com/Aerll/rpp) to allow easy export of rules including more complex features such as grouped tiles. 

Web version is available at [https://imilchshake.github.io/ddnet-automap-creator/](https://imilchshake.github.io/ddnet-automap-creator/).
